## IMU計測テストリポジトリ

## 補正方法

- 生の角速度をSAMPLE_COUNT分計測し、その平均をオフセットとして記録する
- 加速度を利用し、理想のベクトル(真上を向く)に一致させる回転行列を計算する(ロドリゲスの回転公式を応用)

上記の結果を使い補正されたZ軸周りの角速度を得る。

また、現時点(26/06/06)では未完成だが、LPF(ローパスフィルタ)を使った補正も取り入れている。

## 計測手順

1. etrobo環境でビルド、機体へのアップロードを行う

2. シリアルモニタ(ex. [pybricks.com](https://code.pybricks.com/)や[pybricks-ble-monitor](https://fami-gb.github.io/pybricks-ble-monitor/)を使う。)でSPIKEと接続する

3. シリアルモニタに『機体を水平に維持してください』と表示されるので、床の上などなるべく水平な場所に機体を移動させる(約3秒の猶予)

4. フォースセンサを押して計測開始

計測を終了するには、機体のセンターボタンを押します。
